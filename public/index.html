⚠️ No se pudo conectar al servidor

Esta aplicación necesita el backend corriendo. En una terminal, dentro de la carpeta salas-ensayo:

  1. Ejecuta node server.js (o npm start)
  2. Abre http://localhost:3000 en el navegador

¿No tienes Node.js? Descárgalo gratis desde nodejs.org (versión LTS).

🗺 Mapa con Google Maps

Si cargás una clave, el mapa del móvil y del escritorio se dibuja con Google Maps. Sin clave se usa OpenStreetMap (igual que ahora) y todo sigue funcionando. La clave se crea en Google Cloud → Maps Platform habilitando Maps JavaScript API y Geocoding API, y conviene restringirla por referrer.
